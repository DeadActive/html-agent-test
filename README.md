# HTML → ZeroBlock (agent test page)

Page: https://deadactive.github.io/html-agent-test/

Converts HTML to Tilda ZeroBlock JSON in the browser, the same way the Tilda page editor converts a Vibe Block to a
ZeroBlock. Built for AI agents that operate a browser:

1. Open the page with `?width=1200`.
2. Put the HTML into `#html-to-zero-source`.
3. Click `#html-to-zero-convert`.
4. Wait until `#html-to-zero[data-state]` is `done` or `error`.
5. Read `#html-to-zero-result`: the ZeroBlock JSON (compact, one line), or `{"error": "…"}`.

`?width=` is the editor window width (≤1200 → 1200 artboard; up to 1680 adds the 1680 screen; wider adds 1920). Without
it the browser window width is used, which agent browser tools rarely control. Optional: `&breakpoints=320,480,640,960`
passes vibe block breakpoints.

`embed.html` is the same widget as one self-contained snippet (div + inline script) to paste into any page.
`index.html` is that snippet wrapped in a page. Both are generated by `npm run build:agent` in tildazero_importhtml.
